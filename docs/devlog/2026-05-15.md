# 2026-05-15

## Documentation

Effective module documentation is critical for future development on the project, for end-users to understand the implementation of the tool, and for developer collaborators to communicate with each other. A documentation website improves its accessibility. The standard documentation website generator for Python-based projects is Sphinx.

We added a Sphinx documentation website inside the repository, with a development log, automated module documentation based on in-code docstrings, and guides (for later end-user tutorials). We added continuous deployment on the main branch of the repository to ensure documentation is always up to date.

## Application implementation

- We added a function generator which supports sine, square, triangle, sawtooth, pulse, and constant waveforms, along with the required parameters to define their behaviour (e.g., rate in bpm, sample rate, amplitude, offset, phase).
- We added a preview of the waveform generated by the function generator which supports zero- and first-order holds.
- We added the openBF 1-dimensional simulator as an extension to the function generator.
